What the command does

받고, 맞춰 봅니다

최신 버전을 받아 해시를 대조한 뒤에만 설치합니다. 맞지 않으면 아무것도 넣지 않고 멈춥니다.

암호를 묻지 않습니다

응용 프로그램 폴더에 넣고, 쓸 수 없으면 내 계정의 응용 프로그램 폴더로 갑니다. 관리자 권한(sudo)은 쓰지 않습니다.

경고 없이 열립니다

아직 Apple 공증 전이라, 브라우저로 받으면 「Apple이 확인할 수 없습니다」 창에 막힙니다. 이 명령은 격리 표시를 떼고 넣어 바로 열립니다.

Claude Code 는 물어봅니다

없으면 알려 주고, 원할 때만 공식 설치 프로그램을 실행합니다. 없어도 열기·고치기·찾기·노트·내보내기는 모두 됩니다.

새 버전이 나오면 앱이 알려 줍니다. 두 번 누르면 업데이트하고 다시 켭니다. 스크립트는 install.sh 에서 전부 읽어 볼 수 있습니다.
